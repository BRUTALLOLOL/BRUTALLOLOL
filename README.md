### Наукоемкая разработка и Open Source
- **[kernel-experience-tools](https://github.com)** - Библиотека для проецирования ядер памяти в функции опыта. Имплементирует соответствие Kernel-Experience для моделирования памяти в сложных системах.
- **[LapaceX](https://github.com)** - Библиотека для прямого и обратного преобразования Лапласа через вейвлет-декомпозицию в логарифмической плоскости. Идентифицирует экспоненциальные моды с помощью помехоустойчивого анализа гребней CWT.

### Промышленная автоматизация и infrastructure-решения
- **[admin-compass](https://github.com)** - Windows-приложение для консолидации инструментов системного администрирования. Поддерживает организацию и выполнение диагностических команд, бинды утилит, перехват ошибок и работу с системными логами.
- **Система RFID-датчиков** - Реализация логики считывания меток, алгоритмов программного анти-дребезга (debouncing), пользовательского интерфейса и интеграции с заводской базой данных MsSQL.
- **Заводской HelpDesk** - Проектирование и внедрение внутренней системы обработки инцидентов для ИТ-инфраструктуры предприятия.
